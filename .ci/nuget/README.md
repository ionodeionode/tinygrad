# LightGBM NuGet Package

[LightGBM](https://github.com/microsoft/LightGBM) is a gradient boosting framework that uses tree-based learning algorithms.

## Usage

This package provides the native LightGBM library for use with the [LightGBM .NET binding](https://github.com/microsoft/LightGBM/blob/master/docs/Installation-Guide.rst#lightgbm-net-binding).
